# vocab-inquiry

## 使用范围

- 用户调用后，在当前对话后续的词汇提问中持续应用本规则，直到用户要求停止或修改。新对话需重新调用。
- 只处理用户明确询问含义、翻译或用法的词与短语；其他问题正常回答。
- 如果用户只要求开启模式，没有询问具体词汇，简短确认已开启即可。

## 对话命名

- 用户在当前对话首次实际调用本 Skill 查词或开启查词模式时，自动命名为 `YYYY-MM-DD-词汇查询`。日期取首次调用当天的北京时间（`Asia/Shanghai`），依据客户端时间上下文或可核实的当前时间，不直接采用执行主机的本地日期。仅讨论、查看或修改本 Skill 或插件时不执行改名。
- 使用当前宿主实际提供的对话改名能力，只操作已明确识别的当前对话；按工具返回结果判断是否成功，需要时读回标题核实。不把回复中展示的标题当作已经改名，也不猜测接口或直接修改宿主的内部数据。
- 每个对话只在首次调用时尝试一次；后续连续查词、重复开启模式或跨天继续时不重复命名。用户另行指定或手动修改标题后，保留用户的选择。
- 缺少改名能力、无法确认当前对话或改名失败时，用一句话说明自动命名未完成及原因，然后正常回答查词问题；不声称改名成功。成功时不增加改名提示。

## 判断与解释

- 结合当前语境，判断询问词是否表示某个领域中的专门概念，例如技术美术、计算机图形学、数学。词语生僻或出现在技术句子里，不足以判定它是专业词。
- 按询问词的当前含义选择对应译名。例如 normal 在图形学中可指法线，在日常英语中可表示正常；技术句子里的 slightly 仍是普通词。
- 从用户的提问中提取所询问的词或短语作为标题，不把“是什么意思”等提问文字放进标题。
- 语境不足且会影响分类或译法时，只问一个简短的澄清问题。译名不确定时明确说明，不编造公认术语。

## 专业词汇

每次都完整展示英语、日语、中文三种语言，即使相关译名已经在提问或上下文中出现。

标题保留询问词，括号内列另外两种语言的对应译名。括号内按英语、日语、中文的顺序排列，跳过询问词所用的语言：

- 英语询问词：`**询问词**（日语译名，中文译名）：`
- 日语询问词：`**询问词**（英语译名，中文译名）：`
- 中文询问词：`**询问词**（英语译名，日语译名）：`

标题下只有一条中文解释，约 2–3 行。先说明基本含义，再说明作用或一个具体情境，用高中生能理解的语言。需要换行时，在同一个列表项内换行。

```markdown
**询问词**（另外一种语言的译名，另一种语言的译名）：

- 中文解释，约 2–3 行。
```

示例：

**vertex**（頂点，顶点）：

- 三维模型中确定位置的点。  
  顶点连接成边和面，共同构成模型的形状。  
  例如，一个三角面由三个顶点确定。

## 非专业词汇

标题保留询问词，标题下固定三条内容：

1. **中文解释**：详细讲清常用义，优先解释当前语境中的意思；有相关常用义时说明区别，不罗列罕见义。
2. **用法**：说明源语言中常见的搭配、使用场合或语气，按词语实际适用情况选择重点。
3. **例句及翻译**：给一个自然的源语言例句及中文翻译；以自然准确为前提，优先采用建模、材质、纹理、光照、动画等技术美术情境。

释义只翻译成中文。源语言用于询问词、搭配和例句，不补充其他语言的译名。

```markdown
**询问词**

- 中文解释：详细中文释义。
- 用法：源语言的常见搭配、使用场合或语气。
- 例句：源语言例句。——中文翻译。
```

示例：

**slightly**

- 中文解释：稍微、略微，表示程度较小。可以描述轻微的变化，也可以说明两个事物之间只有一点差别，通常不带明显的褒贬。
- 用法：常修饰形容词或比较级，如 slightly blurry（有点模糊）、slightly brighter（稍微更亮）；也可以修饰动作，如 slightly reduce（略微降低）。日常交流和书面说明中都常用。
- 例句：The texture looks slightly blurry.——这张纹理图看起来有一点模糊。

每个查询词单独使用对应格式。除首次调用时自动命名未完成的一句说明外，直接输出词汇内容，不附加分类过程、小标题、总结或练习。
